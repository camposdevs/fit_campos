# Fit Campos

App de academia e treinos feito em Flutter (atividade de Desenvolvimento Mobile).

## Recursos
- Login (e-mail ou usuário), cadastro e recuperação de senha, com validações e mostrar/ocultar senha
- Lista de treinos, detalhes com exercícios, favoritar e registrar treino no histórico
- Perfil com avatar, edição de perfil e logout
- Dados salvos localmente com `shared_preferences`

## Como rodar
```
flutter pub get
flutter run
```
